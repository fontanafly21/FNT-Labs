# FNT Labs

Site da FNT Labs: curso de como ganhar dinheiro com IA e serviços de desenvolvimento web (sites, lojas virtuais, sistemas exclusivos e automações).

Site estático em um único arquivo (`index.html`), sem build. Publicado na Vercel.

## Onde editar
No final do `index.html`, no bloco `CONFIGURAÇÃO`:
- `COURSE_URL`: link do curso na Kiwify
- `WA_LUIS` / `WA_JON`: números de WhatsApp dos sócios
